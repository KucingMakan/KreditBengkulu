# Panduan Kredit Produktif

Web informasi kredit usaha untuk UMKM: penjelasan KMK Rekening Koran, Kredit Investasi, dan KMK Aflopend, checklist berkas pengajuan, dan kalkulator angsuran (flat, sliding, dan rekening koran) dengan suku bunga 11,5% per tahun.

Satu file `index.html`, bisa dibuka offline. Unduh Excel dan PDF butuh koneksi internet.

Simulasi bersifat indikatif. Syarat dan persetujuan kredit mengikuti ketentuan bank.
